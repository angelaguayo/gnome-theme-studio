# 📸 Guía de Capturas de Pantalla (Screenshots Guide)

Coloca aquí tus capturas de pantalla para que se muestren automáticamente en el `README.md` de GitHub.

### Archivos recomendados:

| Archivo | Contenido sugerido | Resolución recomendada |
| :--- | :--- | :---: |
| [`studio.png`](studio.png) | Interfaz web de **GNOME Theme Studio** (`http://localhost:5000`) mostrando el mockup interactivo, selectores de color y controles. | 1920×1080 o similar |
| [`desktop.png`](desktop.png) | **Escritorio GNOME completo** con el tema aplicado: panel superior, fondo de pantalla 4K generado y ventanas abiertas. | 1920×1080 / 4K |
| [`nautilus.png`](nautilus.png) | Detalle de **Nautilus / Libadwaita**, destacando la integración sin desfase (*Zero-gap*) del headerbar y la barra lateral. | 1200×800 aprox. |
| [`firefox.png`](firefox.png) | **Mozilla Firefox** tematizado, mostrando la barra de pestañas, el Omnibox y los botones de ventana en hover. | 1200×800 aprox. |

> **Tip:** Puedes usar la herramienta nativa de capturas de GNOME (`Impr Pant` o `Shift + Ctrl + Impr Pant`) para capturar las áreas deseadas y renombrarlas con los nombres indicados arriba.
